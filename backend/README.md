# FinSight Backend

Spring Boot REST API for FinSight. See the [root README](../README.md) for the live demo, credentials, and full project overview.

## Quick start

```bash
docker compose up -d
export JAVA_HOME=/opt/homebrew/opt/openjdk@21/libexec/openjdk.jdk/Contents/Home
export PATH="$JAVA_HOME/bin:$PATH"
./start-local.sh
```

API runs at http://localhost:8080
